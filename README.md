# World Map Domination — Online Multiplayer

## Run locally
1. Install Node.js.
2. Open a terminal in this folder.
3. Run `npm install`
4. Run `npm start`
5. Open `http://localhost:3000`

To play with people on the same network, use the host computer's local IP address with port 3000.

For public internet play, deploy this project to a Node.js hosting service that supports WebSockets.
